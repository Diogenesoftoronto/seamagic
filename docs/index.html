Capabilities

What seamagic can do

From simple filters to complex scripted pipelines, seamagic handles it all.

5 MCP Tools

Full Model Context Protocol server with 5 tools: view_diff for previewing changes, run_steel for Scheme scripting, edit_image for single operations, create_image for generators, and get_info for metadata.

rmcp stdio transport

Steel Scripting

Write complex image pipelines in Steel Scheme. Chain operations, define reusable functions, and iterate on designs programmatically.

steel-core 0.8

25+ Operations

Filters, transforms, shapes, text overlays, effects, and more. From blur and brightness to glitch art and chromatic aberration.

image 0.25 imageproc

Parallel Processing

Heavy filters use Rayon for data-parallel execution across CPU cores. Process large images without waiting.

rayon 1.10

WebAssembly Ready

The image operations compile to WASM for browser demos and web apps. No server required — process images entirely client-side.

wasm-bindgen no-std compatible
Protocol

MCP Tool Reference

Use these tools through any MCP-compatible client. Each tool returns structured JSON that the model can reason about.

view_diff

Async

Preview changes before committing them. Shows a side-by-side or overlay comparison of the original and modified image. 

{
  "image_id": "abc123",
  "operation": "blur",
  "params": { "sigma": 2.5 }
}

run_steel

Sync

Execute Steel Scheme scripts for complex multi-step pipelines. Access the full image registry and all operations from Scheme. 

(begin
  (define img (load-image "photo.jpg"))
  (blur img 2.0)
  (tint img "#ff6600")
  (save img "output.png"))

edit_image

Sync

Apply a single operation to an image by ID. Returns a new image ID. Operations include filters, transforms, drawing, and text overlays. 

{
  "image_id": "abc123",
  "operation": "brightness",
  "value": 1.2
}

create_image

Sync

Generate new images from scratch. Create gradients, noise, patterns, or solid color canvases to build designs programmatically. 

{
  "width": 800,
  "height": 600,
  "generator": "gradient",
  "colors": ["#ff0066", "#00ccff"]
}

get_info

Sync

Extract metadata from any image in the registry. Dimensions, format, color mode, and file size — useful for conditional logic in scripts. 

{
  "image_id": "abc123"
}

Cyberpunk Glitch Effect

A multi-step pipeline that creates a cyberpunk aesthetic with chromatic aberration, glitch displacement, scanlines, and neon tinting.

cyberpunk_glitch.scm 
(begin
  (define img (load-image "portrait.jpg"))
  ;; Chromatic aberration
  (chromatic-aberration img 3.0)
  ;; Glitch displacement
  (glitch img 8 4)
  ;; Scanlines overlay
  (scanlines img 2 0.3)
  ;; Neon cyan tint
  (tint img "#00ffff" 0.15)
  ;; Vignette for depth
  (vignette img 1.5 0.8)
  (save img "cyberpunk_result.png"))
tcli commands 
seamagic load portrait.jpg
seamagic chromatic-aberration --image latest --strength 3.0
seamagic glitch --image latest --amount 8 --bands 4
seamagic scanlines --image latest --spacing 2 --opacity 0.3
seamagic tint --image latest --color "#00ffff" --intensity 0.15
seamagic vignette --image latest --intensity 1.5 --opacity 0.8
seamagic save --image latest cyberpunk_result.png

Retro Halftone Poster

Emulates classic print aesthetics with halftone dot patterns, contrast boost, and duotone coloring.

retro_halftone.scm 
(begin
  (define img (load-image "photo.jpg"))
  ;; Boost contrast for impact
  (contrast img 1.4)
  ;; Apply halftone dot pattern
  (halftone img 8)
  ;; Red/blue duotone
  (duotone img "#cc0000" "#0000cc")
  ;; Add poster border
  (draw-rectangle img 0 0
    (image-width img) (image-height img)
    "#ffffff" 8.0)
  (save img "retro_poster.png"))
tcli commands 
seamagic load photo.jpg
seamagic contrast --image latest --value 1.4
seamagic halftone --image latest --dot-size 8
seamagic duotone --image latest \
  --color-a "#cc0000" --color-b "#0000cc"
seamagic draw-rect --image latest \
  --x 0 --y 0 --width 800 --height 600 \
  --color "#ffffff" --thickness 8
seamagic save --image latest retro_poster.png

Event Poster with Text

Combine image manipulation with text overlays for event graphics. Includes drop shadow for depth.

poster_from_scratch.scm 
(begin
  ;; Create gradient background
  (define bg (create-image 1080 1350))
  (gradient bg "#1a1a2e" "#16213e")
  ;; Add noise texture
  (noise bg 0.05)
  ;; Add title text with shadow
  (drop-shadow bg 4.0 4.0 8.0 "#000000")
  (draw-text bg "SEAMAGIC" 540 400
    "#e94560" 96 "center")
  ;; Add subtitle
  (draw-text bg "LIVE" 540 520
    "#ffffff" 48 "center")
  ;; Date text
  (draw-text bg "MAY 2025" 540 620
    "#0f3460" 32 "center")
  (save bg "poster.png"))
tcli commands 
seamagic create 1080 1350
seamagic gradient --image latest \
  --from "#1a1a2e" --to "#16213e"
seamagic noise --image latest --amount 0.05
seamagic draw-text --image latest \
  --text "SEAMAGIC" --x 540 --y 400 \
  --color "#e94560" --size 96 --align center
seamagic draw-text --image latest \
  --text "LIVE" --x 540 --y 520 \
  --color "#ffffff" --size 48 --align center
seamagic save --image latest poster.png

Design from Scratch

No source image needed. Generate procedurally with gradients, noise, shapes, and text.

from_scratch.scm 
(begin
  ;; Create canvas
  (define canvas (create-image 1200 800))
  ;; Sunset gradient
  (gradient canvas "#ff7e5f" "#feb47b")
  ;; Add geometric shapes
  (draw-circle canvas 600 400 200
    "#ffffff" 4.0)
  (draw-rectangle canvas 200 200 300 400
    "#00000020" 0.0)
  ;; Overlay text
  (draw-text canvas "HELLO" 600 350
    "#ffffff" 120 "center")
  (draw-text canvas "world" 600 480
    "#ffffff80" 60 "center")
  (save canvas "from_scratch.png"))
tcli commands 
seamagic create 1200 800
seamagic gradient --image latest \
  --from "#ff7e5f" --to "#feb47b"
seamagic draw-circle --image latest \
  --x 600 --y 400 --radius 200 \
  --color "#ffffff" --thickness 4
seamagic draw-text --image latest \
  --text "HELLO" --x 600 --y 350 \
  --color "#ffffff" --size 120 --align center
seamagic save --image latest from_scratch.png

CLI Quick Reference

All commands at a glance. Use --image latest to operate on the most recent image.

load <path> Load an image from disk seamagic load photo.jpg
save --image <id> <path> Save image to disk seamagic save --image latest out.png
blur --image <id> --sigma <f> Gaussian blur seamagic blur --image latest --sigma 2.5
brightness --image <id> --value <f> Adjust brightness seamagic brightness --image latest --value 1.2
contrast --image <id> --value <f> Adjust contrast seamagic contrast --image latest --value 1.5
grayscale --image <id> Convert to grayscale seamagic grayscale --image latest
tint --image <id> --color <hex> --intensity <f> Color tint seamagic tint --color "#ff6600" --intensity 0.3
duotone --image <id> --color-a <hex> --color-b <hex> Two-color duotone seamagic duotone --color-a "#ff0066" --color-b "#00ccff"
vignette --image <id> --intensity <f> --opacity <f> Dark edge vignette seamagic vignette --intensity 1.5 --opacity 0.7
draw-text --image <id> --text <s> --x <i> --y <i> Overlay text seamagic draw-text --text "Hello" --x 100 --y 100 --size 32
draw-rect --image <id> --x --y --width --height --color --thickness Rectangle shape seamagic draw-rect --x 10 --y 10 --w 100 --h 50 --color red
draw-circle --image <id> --x --y --radius --color --thickness Circle shape seamagic draw-circle --x 100 --y 100 --r 50
chromatic-aberration --image <id> --strength <f> RGB channel shift seamagic chromatic-aberration --strength 3
glitch --image <id> --amount <i> --bands <i> Glitch displacement seamagic glitch --amount 8 --bands 4

Get Started

Installation

Choose your preferred method. All options give you the same full-featured binary.

Recommended

Cargo

Install directly from crates.io with Rust's package manager.

cargo install seamagic

Git

Build from source for the latest features and fixes.

git clone https://github.com/diogenesoftoronto/seamagic.git
cd seamagic
cargo build --release

Nix

Declarative install with Nix for reproducible builds.

nix run github:diogenesoftoronto/seamagic

MCP Configuration

Add to your MCP client config (e.g., Claude, Cursor, or custom):

{
  "mcpServers": {
    "seamagic": {
      "command": "/path/to/seamagic",
      "args": ["mcp"]
    }
  }
}
